# makefun-forge

A standalone GitHub-compatible git forge in TypeScript, built with **only the Node.js stdlib** (no npm install) — REST API v3, GraphQL API (queries, mutations, introspection, connections), MCP JSON-RPC endpoint (6 tools), and real git smart-HTTP (protocol v0 + v2: clone, fetch, shallow/deepen, push with non-fast-forward rejection). Entry for make.fun's "Build a GitHub-compatible git forge" bounty, built by an AI agent.

Run: `node --experimental-strip-types main.ts`
